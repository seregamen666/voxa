# Voxa — Android

Аналог Windows-версии (`D:\Apps\voice_dictation`, там называется EchoType), но под
ограничения мобильной ОС: Android не даёт вставлять текст в чужое приложение
"снаружи", поэтому вместо глобального хоткея — **кастомная клавиатура** (Input
Method Service). Ставится вместо системной, в любом текстовом поле есть большая
кнопка "держи — говори".

Package: `com.voxa.dictation`.

## Статус: MVP — проверено на эмуляторе (2026-09-07)

Собрано, установлено и вручную прогнано на Android 14 (Pixel 6, эмулятор
`echotype_test`): включение клавиатуры, переключение на неё, кнопка записи
реально запускает системное распознавание речи (виден индикатор микрофона),
пробел/backspace/enter/переключение клавиатуры — все работают, падений нет.
Единственное, что не удалось проверить на чистом эмуляторе — сам результат
распознавания (нет скачанного офлайн-языкового пакета Google на эмуляторе;
на реальном телефоне обычно уже есть, либо можно поставить в Настройках).

- Экран приложения — оформлен (градиентный бейдж-иконка, карточки шагов),
  включить клавиатуру в настройках, выбрать её как активную
- Иконка приложения — адаптивная, с градиентом и звуковыми дугами вокруг
  микрофона, плюс монохромная версия для Material You
- Сама клавиатура: кнопка записи (push-to-talk), backspace, пробел, enter,
  переключение обратно на обычную клавиатуру
- Распознавание — системный `SpeechRecognizer` с `EXTRA_PREFER_OFFLINE = true`
  (офлайн, если в системе скачан языковой пакет — Настройки → Gboard/Google →
  Голосовой ввод → офлайн-распознавание речи)
- AI-очистка текста (как в Windows-версии) — пока не перенесена

## Инструментарий (поставлен на этой машине)

- JDK 17: `C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot`
- Android SDK: `D:\Apps\android-sdk`
- Gradle 8.7: `D:\Apps\gradle\gradle-8.7` (в проекте уже настроен gradlew)

## Сборка

```bash
cd D:\Apps\voice_dictation_android
.\gradlew.bat assembleDebug
```

APK: `app\build\outputs\apk\debug\app-debug.apk`

## Установка на подключённый телефон

```bash
D:\Apps\android-sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```

Дальше на телефоне: открыть Voxa → «Включить клавиатуру в настройках» →
включить Voxa → вернуться в любое поле ввода → зажать иконку глобуса/сменить
клавиатуру → выбрать Voxa.

## Известные ограничения / что дальше

- Whisper (как на Windows) в само расширение клавиатуры не влезет по памяти —
  системный `SpeechRecognizer` — сознательный компромисс для MVP (см. обсуждение
  в диалоге с Claude 2026-09-07)
- iOS-версия (Swift, Custom Keyboard Extension) не начата — требует Mac с Xcode,
  на этой Windows-машине собрать нельзя
- Нет AI-очистки текста, нет настроек (язык, качество) — только заглушка на минимуме
